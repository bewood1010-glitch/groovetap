# 그루브탭

바이닐 DJ를 위한 BPM 측정기. 박자에 맞춰 화면을 탭하거나, 마이크로 음악을 듣고 자동으로 BPM을 찾습니다.
설치 없이 iPhone Safari에서 열어 홈 화면에 추가해 쓰는 웹앱(PWA)입니다.

**사용하기:** https://bewood1010-glitch.github.io/groovetap/

## 기능

- **탭 모드**: 화면 아무 곳이나 박자에 맞춰 탭. 4번 이상 탭하면 정확해지고, 2초 넘게 쉬면 다음 탭부터 새로 측정합니다.
- **오토 모드**: 마이크로 듣고 BPM을 찾습니다. 최근 4초 음파와 박 위치, 신뢰도를 보여줍니다.
- **듣는 환경**: 집 / 클럽 / 바. 환경에 따라 킥·스네어·하이햇 대역 비중과 분석 구간을 바꿉니다.
- **÷2 / ×2**: 하프타임·더블타임으로 잡혔을 때 바로 보정.
- **화면 꺼짐 방지**: 측정 중에는 화면이 꺼지지 않습니다.
- 오프라인에서도 동작합니다.

## iPhone에 설치

1. Safari에서 위 주소 열기
2. 공유 버튼 → **홈 화면에 추가**
3. 오토 모드를 처음 켤 때 마이크 권한 허용 (거부했다면 설정 › Safari › 마이크)

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면과 스타일 |
| `app.js` | 탭 측정, 오토 모드, 화면 꺼짐 방지 |
| `bpm-core.js` | BPM 자동 감지 엔진 (브라우저·Node 공용) |
| `capture-worklet.js` | 마이크 입력 수집 (AudioWorklet) |
| `sw.js`, `manifest.webmanifest` | 오프라인 캐시, 홈 화면 앱 설정 |
| `test/synth-test.js` | 합성 음원 정확도 테스트 |
| `tools/icon-source.html` | 앱 아이콘 원본 |

### 자동 감지 방식

마이크 소리를 킥(저음), 스네어(중음), 하이햇(고음) 대역으로 나눠 각 대역의 "때리는 순간"(로그 에너지 증가분)을 구하고,
대역별 자기상관을 환경별 비중으로 합쳐 박 간격을 찾습니다. 70–190 BPM 범위에서 찾으며, 서버 없이 폰 안에서만 처리합니다.

## 테스트

```bash
node test/synth-test.js
```

5개 장르 × 3개 환경 합성 음원 30개 기준: 26개 오차 1% 이내, 3개 ½배(드럼앤베이스), 1개 실패.
실제 음악·실제 클럽 환경 정확도는 별도 검증이 필요합니다.

## 업데이트할 때

파일을 바꾼 뒤 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 버전을 받습니다.
